# Client Audit Reporting — Streamlit

A Streamlit app to automate the preparation of client audit reports from a new audit-export CSV and an existing Excel workbook template.

## What it does

- Uses the existing workbook as the template.
- Keeps existing worksheet names and column headers unchanged.
- Applies report-specific filters to the source CSV.
- Avoids adding records whose `internal_id` already exists in the target sheet.
- Shows a summary of matching records and site names that need review.
- Updates the `Pass %` tab monthly for months represented in the current export, using the same report filters and outcome counts. Pass Rate is calculated as Pass / (Visits - Abort).
- Provides the populated workbook as a download from the app.
- Does not modify the original uploaded files.

## Current rules

- **2026 Indy:** `item_to_order` = `E-Cig - No ID`, with `site_code` beginning `IND`, `BAT`, or `C0`, plus WHSmith site names/codes.
- **2026 Qcomm:** `item_to_order` = `Rapid Delivery`, and `site_name` matches a site already listed in the `2026 Qcomm` worksheet.
- **2026 16-17 YOs:** `item_to_order` = `Home Delivery`, and `site_name` matches a site already listed in the `2026 16-17 YOs` worksheet.

Unmatched site names for Qcomm and 16-17 YOs are displayed for review rather than silently added.

## Run locally

1. Install Python 3.10 or newer.
2. Create and activate a virtual environment.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the app:

   ```bash
   streamlit run app.py
   ```

5. Upload:
   - the latest audit-export CSV
   - the existing client workbook template (`.xlsx`)

6. Select **Build report**, review the summary and unmatched-site lists, then download the populated workbook.

## Deploy from GitHub

1. Create a GitHub repository.
2. Add `app.py`, `requirements.txt`, and `README.md`.
3. In Streamlit Community Cloud, select **Create app**, choose the repository and branch, and set the main file to `app.py`.

## Important notes

- This starter project implements the currently agreed rules for the three worksheets present in the supplied workbook. The other two report workflows can be added as we review their files.
- Confirm the exact business meaning of site-code prefix `C0` and the WHSmith naming variants against live exports.
- The app uses the uploaded workbook's existing site names as the allow-list for Qcomm and 16-17 YOs. If new valid sites should be included, review them in the unmatched-site list before changing the rule.
- The downloaded workbook is generated by the app; the intended deliverable is the repeatable Streamlit workflow, not a manually edited Excel file.

## File 4 — The Co-operative
- `2026` tab: 2026 source audits with exact `site_code` `CoopTCG`.
- `Summary`: update monthly 2026 visits, pass, fail, abort, and pass rate for months represented in the export.

## File 5 — Waitrose
- `2026 Retail`: 2026 audits where `site_code` begins `WAI`.
- `2026 Online`: 2026 audits where `site_name` exactly matches `Waitrose.co.uk` (case/spacing insensitive).
- `Pass %`: update monthly retail and online visits, pass, fail, abort, pass rates, and YTD formulas.

## Allocation review and precedence
- Retail rules for Sainsbury's, Tesco, The Co-operative, and Waitrose exclude Home Delivery and Rapid Delivery records, preventing online orders from also entering retail tabs.
- The Co-operative accepts any site code beginning `CoopTCG`.
- The app shows unallocated and multi-match source audits and lets the user export each list to CSV for review.
